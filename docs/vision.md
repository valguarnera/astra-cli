- El CLI nunca depende del hardware.

- El Workspace nunca depende de un driver.

- Los drivers nunca conocen la lógica del Core.

- El Core nunca conoce GPIO.

- Todo se comunica mediante ADP.

- Los nodos son reemplazables.

- Los drivers son intercambiables.

- El Workspace es portable.

- El Workspace nunca almacena archivos generados.

- El Workspace almacena únicamente la intención del usuario.

- `node.yaml` dice qué nodo querés.

- `astra.yaml` dice cómo es el proyecto.

- `secrets.yaml` dice cómo se conecta la instalación.
